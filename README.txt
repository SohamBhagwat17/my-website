SOHAM BHAGWAT — PORTFOLIO WEBSITE

FILES
- index.html: page content and links
- style.css: colours, layout, typography and mobile styling
- script.js: mobile navigation menu
- assets/soham.jpg: your portrait

RUN LOCALLY ON ANDROID
1. Extract this ZIP using your phone's Files app.
2. Open index.html with a browser, or use an Android code editor that supports HTML preview.
3. Keep the assets folder next to index.html so your portrait loads.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a repository named sohambhagwat17.github.io
   (or use an existing repository if you prefer a project URL).
2. Upload index.html, style.css, script.js and the assets folder contents.
3. In the repository, open Settings → Pages.
4. Choose Deploy from a branch, select main and / (root), then Save.
5. Wait for the deployment and open the URL GitHub Pages displays.

EDITING
- Update text and profile links in index.html.
- Change colours and layout in style.css.
- Keep the file names and folder structure unchanged unless you also update the paths.

NOTES
- The website uses Google Fonts when online; system fonts will be used if unavailable.
- The resume PDF was mentioned, but no resume file was available to include here. Add it to the project and link it from index.html when you have it.
- Your phone number is displayed on the page because you supplied it. Remove it if you prefer not to publish it publicly.
